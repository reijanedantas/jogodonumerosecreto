# Jogo do número secreto

Jogo de navegador da formação Alura. A pessoa tenta acertar um número de 1 a 100 e recebe a dica se o palpite foi maior ou menor.

O campo aceita apenas inteiros nesse intervalo. A narração por voz só ocorre quando a biblioteca externa carrega; sem ela, o jogo continua na tela.

## Como abrir

Abra `index.html` no navegador.
